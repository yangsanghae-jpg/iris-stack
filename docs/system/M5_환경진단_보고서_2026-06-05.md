## 2. 0Dev 위치 — iCloud인가?

```
경로:     /Users/iris/Documents/0Dev  (실경로 동일)
CloudDocs 직접 경로: 0Dev 항목 없음
```

`~/Documents` 디렉터리에 다음 xattr가 확인됨:

- `com.apple.file-provider-domain-id`
- `com.apple.fileprovider.detached#B`

→ **macOS "Desktop & Documents" iCloud 동기화가 켜져 있고, 0Dev가 그 안에 있다.**

`brctl status com.apple.CloudDocs`도 2026-06-05 12:03 full-sync 완료 상태를 보여준다. Mobile Documents 경로가 아니어도 **iCloud 동기화 대상**이다.

**리스크:** `_index.db` + WAL/SHM이 iCloud로 오가면 DB 손상·락 충돌·양쪽 머신 동시 쓰기 시 corruption 가능성이 크다.
